📊 SAMANVAY Dashboard

A modern, responsive and premium dashboard built using React.js with clean UI components and smooth user experience.

🚀 Features
⚡ Fast and responsive UI
🎨 Premium modern dashboard design
📱 Fully responsive (mobile + desktop)
📊 Recharts integration for data visualization
🔐 Login & Register pages
🧭 Clean navigation system (Navbar + Sidebar)
🌙 Dark/Light UI ready structure (optional extension)
🧩 Modular component-based architecture
🛠️ Tech Stack
React.js
JavaScript (ES6+)
CSS / Tailwind (as per your setup)
Recharts
React Router DOM

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/your-username/samanvay-dashboard.git

Move into project folder:

cd samanvay-dashboard

Install dependencies:

npm install

Start development server:

npm start
